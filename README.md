# Life Wish Map

「人生でやりたいこと」と「人生でやってきたこと」を切り替えるインタラクティブマップ。

GitHub Pagesを使って公開するための小さなWebサイトです。個人情報を少し一般化した公開版です。Life Wishlist本体（非公開リポジトリ）の内容は含まれません。

## GitHub Pages

1. このリポジトリを **Public** で作成して、`index.html` をルートに置く。
2. Settings → Pages → Build and deployment で **Deploy from a branch** を選択。
3. Branch を **main**、フォルダを **/(root)** にして Save。
4. GitHub Pages の反映後、サイトURLを確認する。

**注意**：Webサイトはインターネット上で誰でも閲覧できる。公開したくない個人的な記録はここに追加しない。

HTMLはCSS・JavaScriptを1ファイルに含むため、ビルドは不要。
